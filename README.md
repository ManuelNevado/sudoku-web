# Central de Pasatiempos

Plataforma web de juegos clasicos. Puzzles y pasatiempos jugables en el navegador.

**Jugar:** https://manuelnevado.github.io/sudoku-web/

## Juegos disponibles

### Sudoku
- Generador procedural con solucion unica garantizada
- 3 niveles de dificultad: Facil, Medio, Dificil
- Sistema de notas/candidatos
- Pistas
- Temporizador
- Maximo 3 errores antes de game over

### Wordle
- Mezcla de palabras en ingles y español (el jugador no sabe el idioma)
- ~5000 palabras entre ambos idiomas
- Palabra del dia (misma para todos)
- 6 intentos para adivinar
- Teclado virtual QWERTY con ñ
- Progreso y estadisticas guardados en localStorage

### Dino Runner
- Clon del T-Rex de Chrome con canvas
- Sprites dibujados pixel a pixel (sin imagenes externas)
- Obstaculos: cactus y pajaros
- Ciclo dia/noche automatico
- Mejor puntuacion guardada en localStorage

### GeoQuiz
- Globo 3D interactivo (globe.gl) con pais resaltado
- Zoom adaptativo segun el tamaño del pais
- Adivina el nombre del pais, la capital y la bandera
- 194 paises con nombres en español
- Autocompletado en los campos de texto
- Banderas reales (imagenes, no emojis)
- Sistema de rachas y puntuacion

## Funcionalidades generales

- Tema oscuro/claro
- Controles por teclado y raton
- Diseno responsive mobile-first
- Design system Warm Neutral + Amber
- Iconos Lucide (sin emojis)

## Tech Stack

HTML + CSS + JavaScript vanilla. Sin framework, sin bundler.
